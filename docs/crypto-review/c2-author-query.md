# Clarification request: concrete k-linear rerandomization in Figure 6

**Prepared for:** Yi Wang, Rongmao Chen, Guomin Yang, Xinyi Huang, Baosheng Wang, and Moti Yung  
**Paper:** *Receiver-Anonymity in Rerandomizable RCCA-Secure Cryptosystems Resolved*, CRYPTO 2021, DOI `10.1007/978-3-030-84259-8_10`, full version [IACR ePrint 2021/862](https://eprint.iacr.org/2021/862).

## Purpose

We are evaluating the concrete `k = 2` construction in Section 6.3 and Figure 6 as a candidate for an experimental anonymous route-discovery protocol. This note asks for clarification of one related-group operation. It does not claim a flaw in the generic Re-T-SPHF framework.

## Implemented interpretation

The transcription uses the length-three Cunningham chain described in Section 6.3:

```text
q prime
p = 2q + 1 prime
r = 2p + 1 prime
```

The implementation treats the source group as the ordinary multiplicative quadratic-residue group `QR*_p`. The inner value used by the tag operation is interpreted literally as

```text
mu(u) = u mod q.
```

For the rerandomization equations to preserve the tag relation under ordinary source-group multiplication, the transcription appears to require

```text
mu(u * v mod p) = mu(u) * mu(v) mod q.
```

## Minimal counterexample

For the valid small Cunningham chain

```text
q = 5
p = 11
r = 23
```

choose `u = 3` and `v = 4`, both in `QR*_11`. Then

```text
u * v mod p       = 1
mu(u * v mod p)   = 1
mu(u) * mu(v) mod q = 3 * 4 mod 5 = 2.
```

The two sides differ. Exhaustive testing gives the same conclusion for every tested nontrivial small chain. The machine-readable report is `reports/c2-k2-small-chain-exhaustive.json`, generated by:

```bash
PYTHONPATH=simulator python tools/c2_k2_exhaustive_check.py
```

The existing large-parameter transcription audit is generated by:

```bash
PYTHONPATH=simulator python tools/generate_c2_k2_audit.py
```

## Questions

1. Is `u mod q` intended as an operation on an exponent representation rather than on the ordinary integer representative of a group element?
2. Is there an implicit isomorphism, encoding, projection, or pairing between the related groups that is omitted from the Figure 6 presentation?
3. Should the source group operation be interpreted differently from multiplication modulo `p`?
4. Is there an erratum or a later implementation containing the intended operation?
5. Can you provide one small complete parameter set and one nontrivial `ReRand` test vector for Figure 6?

## Current project treatment

The transcription remains available as reserved audit suite `0x7f02`, but protocol selection and full rerandomization fail closed. The project has adopted a rendezvous-capability fallback while this question remains unresolved.
