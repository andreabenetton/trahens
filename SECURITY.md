# Security policy

Trahens is a research protocol and simulator. It is not production-ready and must not be used to protect real users, sensitive traffic, or safety-critical systems.

Security claims in this repository are hypotheses unless they are tied to an explicit adversary model, specification invariant, and reproducible test or experiment.

For non-public disclosure of a protocol flaw or repository vulnerability, contact `andrea.benetton@blueteam.ee`. Include the affected specification or commit, adversary assumptions, reproduction steps, and expected impact. Do not include real third-party secrets or traffic captures.
