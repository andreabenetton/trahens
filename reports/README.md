# Reports

Tracked report files are deterministic outputs generated by repository tools.

- `iteration-0002-sweep.csv` - fixed bounded-discovery parameter sweep.
- `iteration-0003-policy-comparison.csv` - fixed broad flood versus expanding rings.
- `iteration-0004-unlinkability-comparison.csv` - identifier-based versus U1 branch-local resource cost.
- `iteration-0005-lifecycle-comparison.csv` - E1 clean transport, loss/duplication, and fresh-branch attack scenarios.
- `iteration-0006-crypto-conformance.json` - deterministic C1 vector and negative-test conformance.
- `iteration-0007-wire-tagging-comparison.csv` - integrated W1/C1/E1 path, link tampering, and ratio-tagging scenarios.
- `baseline.json`, `conservative.json`, `dense.json` - deterministic single-run discovery examples retained for regression and inspection.

Reproduce them with:

```bash
make reproduce
```

The outputs are model results. They are not deployment benchmarks or cryptographic proofs.
