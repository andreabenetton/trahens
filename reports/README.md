# Reports

Tracked report files are deterministic outputs generated by repository tools.

- `iteration-0002-sweep.csv` - fixed bounded-discovery parameter sweep.
- `iteration-0003-policy-comparison.csv` - fixed broad flood versus expanding rings.
- `iteration-0004-unlinkability-comparison.csv` - identifier-based versus U1 branch-local resource cost.
- `iteration-0005-lifecycle-comparison.csv` - E1 clean, faulted, and fresh-branch attack scenarios.
- `iteration-0006-crypto-conformance.json` - deterministic C1 component conformance.
- `iteration-0007-wire-tagging-comparison.csv` - integrated C1 ratio-tag negative control.
- `iteration-0008-message-cell-capacity.csv` - variable-message/fixed-cell capacity comparison.
- `iteration-0008-lifecycle-fragmentation.csv` - multi-cell lifecycle and loss comparison.
- `iteration-0009-c2-active-security.csv` - C1 negative-control versus symbolic C2 mutation scenarios.
- `iteration-0011-r1-gate-b.csv` - active R1 discovery and post-READY rendezvous comparison.
- `iteration-0012-t1-reliability.csv` - unrecovered W2 versus T1 recovery under independent loss.
- `iteration-0012-t1-trace-equivalence.csv` - active-versus-empty fixed-schedule trace comparison.
- `iteration-0013-t2-congestion.csv` - fixed, adaptive, and work-conserving overload/fairness comparison.
- `iteration-0013-t2-schedule-leakage.csv` - simple rate-class activity distinguisher and CHAFF cost.
- `iteration-0013-t2-burst-loss.csv` - independent versus Gilbert-Elliott loss at equal nominal mean loss.
- `iteration-0013-t2-multilink-correlation.csv` - lag-one public-count correlation across two modeled links.
- `baseline.json`, `conservative.json`, `dense.json` - deterministic single-run discovery examples.

Reproduce all tracked outputs with:

```bash
make reproduce
```

These are model results, not deployed-network benchmarks or proofs. The T2 leakage classifier is deliberately simple: a failure against it rejects a claim, while success against it would not establish anonymity. The Gilbert-Elliott comparison is a stress model rather than a validated channel model for any deployment.
